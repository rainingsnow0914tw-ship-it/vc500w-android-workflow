# VC-500W：Android 白燈直連與整圖列印實測

這是一份獨立使用經驗，分享已實測的操作流程與其限制。不是Brother官方工具，也不是韌體補丁。[English](README.md)

## 這次真正有效的一步

手機連到印表機SSID後，還要處理「網際網路可能無法使用」提示，明確選 **「僅此次連接」**。本次Samsung手機接受這條沒有網際網路的Wi-Fi後，預設路由、Color Label Editor 2與9100狀態通訊一起恢復。

測試環境為Galaxy S25 Ultra、Color Label Editor 2 1.1.6、50mm CZ紙卷。之後做了120秒完全不查詢設備的熄屏測試、App重開，以及兩個各一份的實際列印。兩張都確認出紙與裁切，第二張整體亮度和色彩較合適。

這只能證明本次路徑有效，不能宣稱所有VC-500W斷線都是同一原因。

## 下次可照這樣用

1. 先在可上網環境把照片、背景、文字和裝飾做成完整圖片，保存好。
2. 核對實際紙卷寬度與剩餘紙張，再準備列印。
3. 印表機Wi-Fi白燈是直連；藍燈是經家裡路由器。依原廠說明選正確模式。
4. 手機系統Wi-Fi清單選自己那台 `Brother VC-500W XXXX`，在無網際網路提示選「僅此次連接」或手機上相同意思的選項。
5. 回App，等印表機／位址讀回。進 **Photo→選成品圖→方向→Next→Option**；本次橫圖選Horizontal。
6. 看完整預覽有沒有裁掉或拉伸，核份數，先印一份。結果不明不要一直按Print。
7. 確認實物後回到平常Wi-Fi。

一般使用者不需要ADB或USB偵錯。若開發者手機另問是否允許無線偵錯，那不是列印所需權限。

## 幾個容易混淆的地方

- SSID已連上、ping有回應、App可通訊、紙張真的印出，是四個不同層次。
- 本次App曾提示Enable Port9100，但接受正確網路後埠和狀態讀取就正常，沒有開埠或刷韌體。
- 「切換至行動數據」原本就是關閉的；本次沒有藉由關行動數據修復。不要照抄其他手機的開關設定。
- 新圖清楚不代表印表機解析度提高：主體更大、照片更亮、構圖更適合小尺寸，也會讓印品容易辨識。
- 生成式照片融合可能重繪細節；若要求原照像素不變，應保留照片圖層再合成背景。
- 3:2圖形與50mm紙卷可用約75×50mm作版面估計，實際邊距／進紙／裁切須以實物量測。

## 補丁與尚未解決的部分

未找到已核實能直接修好所有Android連線問題的補丁。GitHub有閒置保活方向，但作用在該程式自己的TCP連線，不能直接修補官方App。韌體版本檔名／secure與v1清單也不足以判斷某台機器應刷哪一個；這次完全沒有刷韌體。

隔夜、拔線深度待機、家用路由器模式長期穩定、其他紙寬／手機以及校準色準都尚未驗證。本儲存庫不含私人照片、家用SSID、序號、原始裝置紀錄或韌體包。
